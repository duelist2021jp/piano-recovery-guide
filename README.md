# piano-recovery-guide
A web application for pianists returning from a long break, providing a gradual and effective path to resume playing.

## 📌 リポジトリ概要

長年ピアノ演奏を続けていた人が、数年間のブランク後に無理なく演奏力を取り戻すための、ブラウザ完結型ガイドアプリです。  
診断結果に応じて、段階的な練習プラン、AIによる練習曲推薦、進捗の可視化を提供します。

### このリポジトリでできること

- ブランク期間や過去の演奏レベルをもとにした5問のレベル診断
- 診断結果に基づくフェーズ別練習プラン（Phase 1〜4）
- チェックリスト形式での練習項目管理
- 練習記録（時間・メモ・気分）の保存
- Chart.jsによる練習時間の可視化
- 達成バッジによるモチベーション維持
- Google Gemini APIを使った練習曲推薦

### 想定ユーザー

- 学生時代や過去にピアノ経験があるが、しばらく離れていた人
- 何から再開すべきか分からず、段階的な再開プランがほしい人
- 練習の継続を、記録と可視化で支えたい人

### 主な画面フロー

1. ホーム画面から診断を開始
2. 診断結果で推奨開始フェーズと想定リカバリー期間を確認
3. ダッシュボードで当日の練習メニューと進捗サマリーを確認
4. 練習プランで各項目を実施・チェック
5. 必要に応じてAI推薦曲を取得
6. 進捗管理画面で練習ログを保存し、履歴とグラフで振り返る

## ✨ 主な機能

### 1. 📋 レベル診断
- ブランク期間、以前のレベル、練習時間などを分析
- 個別化された開始レベルと予想リカバリー期間を提示
- あなたの強みと重点領域を特定

### 2. 🎯 段階的な練習プラン
- **Phase 1**: 基礎の再構築（2-4週間）
- **Phase 2**: テクニックの復活（4-8週間）
- **Phase 3**: レパートリーの拡大（8-12週間）
- **Phase 4**: 上級への道（継続的）

各フェーズには具体的な練習項目とチェックリストが含まれています。

### 3. 🤖 AI推薦システム
- Google Gemini APIを活用
- あなたのレベルと目標に基づいた練習曲の推薦
- 各曲の難易度、推薦理由、練習のポイントを提供

### 4. 📊 進捗管理
- 日々の練習時間を記録
- グラフで進捗を可視化
- 達成バッジシステム
- 週次・月次レポート

## 🚀 使い方

### 1. セットアップ

このプロジェクトはシンプルなHTML/CSS/JavaScriptで構築されているため、特別なビルドプロセスは不要です。

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/piano-recovery-guide.git

# ディレクトリに移動
cd piano-recovery-guide

# ブラウザで index.html を開く
# または、ローカルサーバーを起動
python -m http.server 8000
# または
npx serve
```

### 2. Gemini APIキーの取得

1. [Google AI Studio](https://makersuite.google.com/app/apikey)にアクセス
2. Googleアカウントでログイン
3. 「Create API Key」をクリック
4. 生成されたAPIキーをコピー
5. アプリの設定画面（フッターの「設定」ボタン）からAPIキーを登録

### 3. 診断を開始

1. ホーム画面の「診断を始める」ボタンをクリック
2. 5つの質問に回答
3. 診断結果を確認
4. 「練習を始める」でダッシュボードへ

### 4. 練習プランを確認

- ダッシュボードから現在のフェーズを確認
- 「練習プラン」セクションで詳細な練習項目を確認
- 各項目をチェックして進捗を記録

### 5. AI推薦を活用

- 「曲の推薦」セクションで「推薦を取得」ボタンをクリック
- Gemini AIがあなたに最適な練習曲を3曲提案
- 各曲の難易度、推薦理由、練習のポイントを確認

### 6. 進捗を記録

- 「進捗管理」セクションで日々の練習を記録
- 練習時間、完了した項目、メモ、気分を入力
- グラフで練習時間の推移を確認
