APIキーはブラウザに安全に保存されます（サーバーには送信されません）

APIキーの取得方法

  1. Google AI Studio にアクセス
  2. Googleアカウントでログイン
  3. 「Create API Key」をクリック
  4. 生成されたAPIキーをコピーして上記に貼り付け

APIキーは20文字以上の英数字、ハイフン、アンダースコアで構成されています

データのリセット
